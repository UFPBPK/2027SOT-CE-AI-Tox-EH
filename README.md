# 2027SOT-CE-AI-Tox-EH

This repository contains the raw data and code files for relevant presentations in the 2027 Society of Toxicology (SOT) Continuing Education (CE) course: Applications of machine learning and artificial intelligence approaches to advance toxicology and environmental health sciences – Part II.

Course Chair: Zhoumeng Lin, University of Florida, Gainesville, FL

Course Co-Chair: Julia Rager, University of North Carolina, Chapel Hill, NC

Primary endorser: Computational Toxicology Specialty Section

Other Endorsers: Biological Modeling Specialty Section and Risk Assessment Specialty Section

Presentation #1: Application of machine learning approaches to support safety assessment and regulatory compliance of animal-derived food products

Presenter #1: Zhoumeng Lin, University of Florida, Gainesville, FL

Presenter #2: Jessie Chappel, University of North Carolina at Chapel Hill, Chapel Hill, NC

Presentation #4: From engineered nanomaterials to nanoplastics: AI-empowered computational modeling for nanotoxicity assessments
